# Candidate Score Management System

This project is a Python-based CRUD application to manage candidate skill scores.

## Features
- Create CSV with default records
- Insert new candidate records
- Display all records
- Update candidate scores and grade
- Delete candidate records
- Streamlit-based web UI

## Tech Stack
- Python
- Pandas
- Streamlit
- CSV file storage

## How to Run (Streamlit)
```bash
pip install streamlit pandas
streamlit run app.py
